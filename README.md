# jwatch-firmware
A firmware based on InfiniTime v1.16.0 that turns the PineTime into the best fitness tracker ever.


# A few features:

OpenHaystack support

Fitness rings (like Apple Watch)

Nightstand mode (like Standby on Apple Watch)

Mindfulness app

Custom vibro patterns

Tilt parallax (watchface moves with accelerometer)

Night mode (increases screen warmth after bedtime)

Sleep tracking

Ring streak tracking

etc.

# Flashing

Use Gadgetbridge on Android, InfiniTimeOrg/InfiniLink on iOS, Watchmate or Siglo on Linux for flashing
